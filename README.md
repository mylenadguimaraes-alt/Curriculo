# Currículo em HTML e CSS

## Sobre o Projeto

Projeto desenvolvido para criar um **currículo online utilizando HTML e CSS**, com o objetivo de apresentar informações profissionais, formação acadêmica, cursos, projetos e formas de contato.

O projeto foi desenvolvido com foco na prática de **estruturação de páginas HTML, estilização com CSS e criação de um layout organizado e responsivo**.

## Funcionalidades

- Apresentação de informações pessoais e profissionais.
- Objetivo profissional.
- Formação acadêmica.
- Cursos complementares.
- Apresentação de projetos desenvolvidos.
- Links para GitHub e LinkedIn.
- Link direto para contato por e-mail.
- Layout organizado em seções.
- Design adaptável para diferentes tamanhos de tela.

## Tecnologias Utilizadas

- HTML5
- CSS3
